# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique code and descriptions rather than people,
and keep discussions on topic. Report unacceptable behaviour to the maintainers by opening a
private security advisory or contacting them through their GitHub profiles. Maintainers may
remove comments, close issues or block participants who violate these standards.
